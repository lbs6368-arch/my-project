# 안산도시공사 업무 산출물 저장소

안산도시공사 관련 문서·분석 산출물을 관리하는 저장소입니다.

## 구성

| 분류 | 산출물 |
|---|---|
| 사장 특강 | 강연 원고(초안·수정본), 발표 시나리오, 연출 통합 대본, 발표자료(PPTX), 통합 PDF |
| KPI 경영혁신 | 성과지표 체계(안), 도입 보고서, 실적관리 대시보드, 지표정의서(IPO) 세트 |
| 법적 검토 | 재활용품 매각 복수낙찰 제한 법적 검토보고서, 행안부 질의서(초안) |
| 부가가치세 | 사업별 과세·면세 판정표, 지방공기업 부가세 정리 보고서 |

## 안내

- 각 산출물은 작업 브랜치에서 작성되며, Pull Request를 통해 `main`에 반영됩니다.
- 문서 형식: HWPX(한글), XLSX(엑셀), PPTX(파워포인트), PDF.
